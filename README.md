# AGV GmbH

Digital Ventures. Infrastructure. Intelligence.

A modern corporate website for Achim Guha Versand GmbH — built with Next.js, Tailwind CSS, and shadcn/ui.

**Live:** https://agv-gmbh.vercel.app

## Tech Stack

- **Framework:** Next.js 13
- **Styling:** Tailwind CSS + shadcn/ui
- **Fonts:** Inter (sans), CalSans (headings)
- **Deployment:** Vercel

## Pages

- `/` — Hero + Bento Grid + Ventures
- `/projects` — Portfolio overview
- `/blog` — Insights and articles
- `/newsletter` — Subscription page
- `/contact` — Contact information
- `/shop` — Coming soon
- `/login` — VIP access
- `/imprint` — Legal imprint (Germany)
- `/privacy` — Privacy policy
- `/terms` — Terms of service

## Setup

```bash
npm install --legacy-peer-deps
npm run dev
```

## Deployment

```bash
npx vercel --prod
```
